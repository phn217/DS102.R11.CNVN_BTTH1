# DS102.R11.CNVN_BTTH1

# Giới thiệu

Gồm hai nội dung: 
- (1) Xây dựng thuật toán Newton–Raphson tìm điểm cực trị của hàm thực vector bằng NumPy
- (2) Thu thập dữ liệu ô tô từ website

## Danh sách file

- `01_newton_raphson.py`: cài đặt thuật toán Newton–Raphson bằng Python và NumPy
- `02_bao_cao.ipynb`: notebook trình bày quá trình thực hiện và báo cáo tổng quan về dữ liệu thu thập
- `crawl_cars.py`: mã nguồn thu thập dữ liệu ô tô từ website
- `cars_raw.csv`: dữ liệu ô tô thu thập được, lưu dưới định dạng CSV
- `README.md`: giới thiệu và mô tả các file
